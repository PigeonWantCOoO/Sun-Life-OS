# 变更记录 / Changelog

## [0.1.0] - 2026-10-18

初始公开版本 / Initial public release.

- Codex Skill：快速记录、十域完整日报、专项咨询，以及周报和月报；建议遵循孙学、薄肌、黄毛与 AI 反馈四层框架。
- 双层记忆：原话与结构化事实保留来源，假设与画像独立管理，区分跳过、未知、未回答与明确否定。
- 确定性本地存储：仅用 Python 标准库，UTF-8 JSON 文件输入、操作重试、写锁、原子文件写入和完整性验证。
- 精确隐私控制：查看、分析排除、按 ID 预览并确认删除；跟踪派生内容、inbox 与崩溃残留，导出未加密完整 ZIP。
- 日报建议与周/月复盘报告：记录实际来源 ID、覆盖缺口和可核对行动反馈。
- 单元测试、虚构 fixtures、端到端工作流检查与公开发布隐私验证。
- 插件元数据与 MIT 许可证；中文主 README、完整英文 README，以及隐私、安全和贡献说明。提供手动安装，未声明市场上架。

- Codex Skill for quick records, full ten-domain daily check-ins, focused advice, and weekly/monthly reviews using the Sun theory, Lean-muscle foundation, Huangmao agency, and AI feedback layers.
- Two-layer memory with provenance for original words and structured facts, separate hypotheses and profiles, and distinct skipped, unknown, unanswered, and explicit negative responses.
- Deterministic local storage using only the Python standard library, UTF-8 JSON file inputs, operation retries, writer locking, atomic file writes, and integrity validation.
- Precise controls for viewing, analysis exclusion, ID-based deletion preview and confirmation; handling derived content, inbox inputs, and crash remnants; and complete unencrypted ZIP export.
- Daily advice and weekly/monthly review reports with actual source IDs, coverage gaps, and testable action feedback.
- Unit tests, fictional fixtures, an end-to-end workflow check, and public-release privacy validation.
- Plugin metadata and the MIT license, Chinese primary and complete English READMEs, plus privacy, security, and contribution guidance. Manual installation is documented without claiming a marketplace listing.
